# Forguncy 선택 항목 보고서 출력 데모

Forguncy(노코드 플랫폼)의 **보고서(Report) 기능**을 사용해, 목록에서 사용자가 선택한 항목만 골라 보고서로 출력하는 데모입니다.
전체 목록을 한 번에 출력하는 대신, 체크박스 등으로 선택한 행만 별도의 보고서(인쇄/PDF)로 만드는 방법을 확인할 수 있습니다.

## 🔗 데모 바로가기

👉 [데모 실행하기](https://demo.forguncy.co.kr/SelectedReport)

## 🧩 핵심 포인트: 선택 항목 기반 보고서

- 리스트뷰에서 원하는 행(들)을 체크박스로 선택
- 선택된 데이터만 보고서 디자이너로 전달
- 코딩 없이 인쇄/PDF 출력용 보고서 생성

## 📋 주요 기능

- 목록에서 항목 선택 (단일/복수)
- 선택된 항목만 보고서로 미리보기
- 보고서 인쇄 및 PDF 출력

## ℹ️ Forguncy란?

Forguncy는 코딩 없이 드래그 앤 드롭 방식으로 웹 애플리케이션을 만들 수 있는 MESCIUS의 노코드 개발 플랫폼입니다. 견적서, 발주서, 검사성적서 등 다양한 업무용 문서를 보고서 기능으로 손쉽게 출력할 수 있습니다.
